# Terra-Gen Intelex Solution Design

This repository contains the governed solution-design record and supporting evidence for Terra-Gen's Intelex implementation.

Start with the [documentation portal](<docs/phase 1/README.md>). It provides the phase and domain map, ADR status totals, repository conventions, source-artifact guidance, cross-domain architecture, and known design gaps.

## Repository Contents

- `docs/phase 1/` contains Document Control, Employee Management, Inspections, Intelex Platform Administration, and Training and Competency Management documentation, plus the Phase 1 change log and consolidated open-task register.
- `docs/phase 2/` contains the current Incident Management design documentation.
- Each domain keeps architecture decision records in `ADRs/` and supporting meeting transcripts in `raw artifacts/meeting_transcripts/`.
- `content/phase 1/training management/` contains two supplied packaged-learning samples for compatibility testing: **Terra Gen Incident Reporting** and **Terra-Gen Fleet Safety Training**. Their presence is test input, not evidence that Intelex compatibility has been validated.

## Current Snapshot

- Phase 1: 60 active ADRs (36 accepted, 24 proposed) plus one superseded historical ADR.
- Phase 2: 3 active Incident Management ADRs (1 accepted, 2 proposed).
- Source evidence: 20 transcript files representing 8 unique meetings; shared workshop copies are byte-for-byte identical across the domains that use them.

ADR status is authoritative. A proposed ADR or an item discussed in a transcript must not be treated as an approved implementation requirement.
