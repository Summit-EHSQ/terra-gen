# Phase 2

Phase 2 currently contains the Incident Management solution-design documentation. The component was moved from Phase 1 because Incident Management is not part of the Phase 1 implementation scope.

[Documentation portal](<../phase 1/README.md>) · [Incident Management](<incident management/README.md>)

## Scope

The current Phase 2 material establishes foundational Incident Management decisions for incident attribution, privacy-aware access, and contractor participation. Detailed incident intake, investigation, classification, regulatory reporting, corrective-action workflows, delivery milestones, and other Phase 2 applications remain to be defined.

## Phase Boundary

Phase 1 provides shared employee, platform, inspection, document-control, and training foundations that Incident Management may consume. References to Incident Management in Phase 1 ADRs describe dependencies, integration boundaries, or future behavior; they do not place the Incident Management application itself in Phase 1 scope.
